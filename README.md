## 使用的一些特定组合：

- **sth** :指something。这里指代 某物或某事，指代一个不确定或未明确说明的东西。

- **sb**:指somebody。意思是某人。

- **sw**:指somewhere。意思是某处。

- **(-er)**:指某个词相关的职业

- **(-ing)**:指某个词的ing（进行时）形式

- **(-ed)**:指某个词的过去式

- **(-s)**:指某个词的复数/第三人称单数形式
